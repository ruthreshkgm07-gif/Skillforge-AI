# SkillForge AI — Data Model & Architecture Decisions

This document outlines key technical design decisions for the PostgreSQL + `pgvector` database schema and Java Spring Boot JPA integration in **SkillForge AI**.

---

## 1. Vector Embeddings (`vector(768)`) & Gemini AI Integration

### Dimension Selection
We standardize all embedding columns (`resume_embeddings.embedding` and `jobs.embedding`) to **768 dimensions**:
* **Provider Model:** Google Gemini API (`text-embedding-004`).
* **Rationale:** 768-dimensional embeddings provide state-of-the-art semantic precision while maintaining manageable index sizes and low latency for nearest-neighbor vector searches.

### Vector Distance Metric
* **Operator:** Cosine Similarity (`vector_cosine_ops` / `<=>` in `pgvector`).
* **Rationale:** Cosine distance measures orientation similarity regardless of text length, making it optimal for comparing candidate resume vectors with job requirement vectors.

---

## 2. Vector Indexing Strategy: HNSW vs. IVFFLAT

We use **HNSW (Hierarchical Navigable Small World)** indexes:
```sql
CREATE INDEX idx_resume_embeddings_vector 
ON resume_embeddings 
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

### Why HNSW over IVFFLAT?
1. **Empty Table Resiliency:** IVFFLAT requires pre-existing data rows during creation to compute cluster lists. HNSW can be built immediately on empty schema initialization without failing or requiring re-indexing.
2. **Superior Query Performance:** HNSW offers higher query recall and faster search execution times under real-world concurrent traffic.

---

## 3. Structural Flexibility with `JSONB`

`JSONB` columns are utilized selectively where fixed SQL column schemas would be rigid and inefficient:

* **`career_roadmaps.plan` (`JSONB`):** Stores structured 3/6/12-month milestone trees (topics, resources, projects, timeline checkpoints) generated by Google Gemini.
* **`interview_sessions.transcript` & `feedback` (`JSONB`):** Stores variable-length Q&A conversation rounds, question category tags, and granular multi-dimensional feedback breakdown.
* **`jobs.required_skills` (`JSONB`):** Holds array of required skills with minimum experience levels.
* **`placement_predictions.factors` (`JSONB`):** Captures dynamic feature importance scores returned by the Scikit-learn ML microservice.

---

## 4. Java Spring Boot JPA & Vector Mapping Approach

### Native Integration Strategy
To map PostgreSQL `vector(768)` columns seamlessly in Spring Data JPA:
1. **Dependency:** `com.pgvector:pgvector` (version `0.2.0`) is configured in `backend/pom.xml`.
2. **Column Mapping:** JPA entities (`Job`, `ResumeEmbedding`) map vector attributes using `@Column(name = "embedding", columnDefinition = "vector(768)")`.
3. **Repository Querying:** Custom native queries utilize `pgvector` distance operators:
   ```java
   @Query(value = "SELECT j.* FROM jobs j WHERE j.status = 'ACTIVE' ORDER BY j.embedding <=> CAST(:queryEmbedding AS vector) ASC LIMIT :limit", nativeQuery = true)
   List<Job> findTopMatchingJobs(@Param("queryEmbedding") String queryEmbedding, @Param("limit") int limit);
   ```
